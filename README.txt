GCH PWA

1. Upload index.html, manifest.webmanifest, sw.js and icons/ to the same GitHub Pages folder.
2. Keep admin.html separate or in the same repo as desired.
3. Open the HTTPS GitHub Pages URL on Android Chrome/Samsung Internet.
4. Use browser menu -> Install app / Add to Home screen.
5. The first install can be tested after a hard refresh; the service worker may take one reload to become active.

This is the first PWA layer. It does not change Supabase logic.
